# 3d-Print-Seva

Приложение для учёта заказов и расходов 3D-печати.

## Что это

Это одностраничный веб-контроллер для учёта:
- заказов и статуса оплаты;
- расходов на материалы и оборудование;
- баланса, прибыли и рекомендаций по ценам.

Данные сохраняются локально в браузере через localStorage.

## Как запустить локально

Откройте файл `index.html` в браузере или запустите локальный сервер:

```bash
cd /workspaces/3d-Print-Seva
python3 -m http.server 3000
```

После этого откройте `http://localhost:3000`.

## Как опубликовать

Это статический сайт, поэтому его удобно публиковать на:
- GitHub Pages;
- Netlify;
- Vercel;
- любой статический хостинг.

Для GitHub Pages достаточно загрузить содержимое репозитория в ветку `main` или `gh-pages` и включить Pages для неё.
